# Hermex Plus — Баги и улучшения

## 🐛 Баги

### 1. Пустое scheduled-сообщение
**Серьёзность:** Medium
Через кнопку «Chat» на главном экране можно запланировать отложенное сообщение без текста. Нужна валидация — не давать schedule при пустом поле.

### 2. Share Sheet не сохраняет контент
**Серьёзность:** High
При шеринге ссылки из браузера → Hermex → открывается пустой чат, как будто пользователь просто зашёл что-то написать. Ссылка не сохраняется. Должно: автоматически создать saved message с расшаренным контентом.

### 3. Кнопка «Сохранить» нестабильна
**Серьёзность:** Medium
Иногда в long-press меню сообщения нет кнопки Save. Появляется/пропадает без явной закономерности.

## ✨ Фичи

### 4. Schedule message изнутри чата
Сейчас запланировать сообщение можно только с главного экрана через кнопку Chat. Нужна возможность schedule прямо внутри чата — например, долгое нажатие на Send.

### 5. Pin сообщений
Возможность закрепить сообщение вверху чата (как в Telegram). Показывает закреплённое при каждом открытии.

### 6. Поменять местами Schedule ↔ Send
Кнопка Send должна быть справа, Schedule слева (или наоборот — главное чтобы Send был на привычном месте).

## ⚡️ Производительность

### 7. Плавность скролла и анимаций
- Скролл в чате рывками
- Анимации переходов между экранами не плавные
- Нужен аудит по стандартам Apple (Core Animation, diffable data sources)
